# Descripción
What does asm1(0x3fa) return? Submit the flag as a hexadecimal value (starting with '0x').  
NOTE: Your submission for this question will NOT be in the normal flag format.  
[Source](https://challenge-files.picoctf.net/...)

# Solución

El objetivo es **trazar manualmente la ejecución** del ensamblador x86 con el argumento `0x3fa`.

#### Convención de llamada x86 (cdecl)
En x86, el argumento pasado a la función se encuentra en `[ebp+0x8]`.  
Por lo tanto, `[ebp+0x8] = 0x3fa`.

#### Traza de ejecución paso a paso

| Offset  | Instrucción            | Evaluación                                |
| ------- | ---------------------- | ----------------------------------------- |
| `<+0>`  | `endbr32`              | Protección, no altera flujo               |
| `<+4>`  | `push ebp`             | Guarda frame pointer                      |
| `<+5>`  | `mov ebp, esp`         | Establece nuevo frame                     |
| `<+7>`  | `cmp [ebp+0x8], 0x2a7` | ¿`0x3fa > 0x2a7`? → **SÍ** (1018 > 679)   |
| `<+14>` | `jg 0x11d3 <asm1+38>`  | Condición verdadera → **salta a +38**     |
| `<+38>` | `cmp [ebp+0x8], 0x48b` | ¿`0x3fa == 0x48b`? → **NO** (1018 ≠ 1163) |
| `<+45>` | `jne 0x11e4 <asm1+55>` | Condición verdadera → **salta a +55**     |
| `<+55>` | `mov eax, [ebp+0x8]`   | `eax = 0x3fa`                             |
| `<+58>` | `add eax, 0x15`        | `eax = 0x3fa + 0x15 = 0x40f`              |
| `<+61>` | `pop ebp`              | Restaura frame                            |
| `<+62>` | `ret`                  | Retorna `eax`                             |

#### Cálculo final
0x3fa + 0x15 = 0x40f
# Notas
la bandera no viene en el formato tradicional
- La instrucción clave es que `0x3fa > 0x2a7`, lo que desvía el flujo al bloque de comparación con `0x48b`. - Como `0x3fa ≠ 0x48b`, se ejecuta la rama `add eax, 0x15` (no `sub`). - El valor `0x2235` al final del archivo es metadata del servidor, no código.
