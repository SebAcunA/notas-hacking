#### Descripción

What does asm2(0x8,0x2e) return? Submit the flag as a hexadecimal value (starting with '0x'). NOTE: Your submission for this question will NOT be in the normal flag format. [Source](https://challenge-files.picoctf.net/c_fickle_tempest/e52eb78a50fe37d5d90fa3200de17edb7b6e51a3e01c583cec0ed94d9e9bc306/test.S)
#### Solución

El objetivo es **trazar manualmente la ejecución** del ensamblador x86 con los argumentos `0xb` y `0x2e`.

**Convención de llamada x86 (cdecl)

- `[ebp+0x8]` = primer argumento = `0xb` (11 decimal)
- `[ebp+0xc]` = segundo argumento = `0x2e` (46 decimal)

| Variable    | Valor inicial | Rol                  |
| ----------- | ------------- | -------------------- |
| `[ebp-0x4]` | `0x2e` (46)   | Acumulador / retorno |
| `[ebp-0x8]` | `0xb` (11)    | Contador del loop    |

```asm
<+22>: jmp <asm2+35>          ; salta directo a la condición

<+24>: add [ebp-0x4], 0x1    ; ← cuerpo del loop
<+28>: add [ebp-0x8], 0xed   ;

<+35>: cmp [ebp-0x8], 0xe6da ; condición: ¿contador <= 0xe6da?
<+42>: jle <asm2+24>         ; si sí → repite el loop
<+44>: mov eax, [ebp-0x4]    ; si no → retorna acumulador
```

Es un **while** que:

- Suma `0x1` al acumulador (`[ebp-0x4]`)
- Suma `0xed` al contador (`[ebp-0x8]`)
- Repite **mientras** `[ebp-0x8] <= 0xe6da`

Después de `n` iteraciones:

```
[ebp-0x8] = 0xb + n × 0xed
```

Necesitamos encontrar `n` tal que `[ebp-0x8] > 0xe6da`:

```
0xb + n × 0xed > 0xe6da
11  + n × 237  > 59098
n × 237        > 59087
n              > 249.31...
→ n = 250 iteraciones
```
**Verificación

| Iteración | `[ebp-0x8]`                   | `<= 0xe6da`? |
| --------- | ----------------------------- | ------------ |
| 249       | 11 + 249×237 = 59024 (0xe6b0) | sí, continúa |
| 250       | 11 + 250×237 = 59261 (0xe77d) | no, sale     |

***Valor de retorno

```
[ebp-0x4] = 0x2e + 250 = 46 + 250 = 296 = 0x128
```

**Flag

```
0x128
```

#### Notas

- El flujo salta primero a la condición (`+35`) antes de ejecutar el cuerpo, comportándose como un **while** clásico.
- `[ebp-0x4]` es el acumulador que se retorna; `[ebp-0x8]` solo controla cuántas veces corre el loop.
